# Complete Terrasense app bundle

This archive contains the full Streamlit app source needed by app.py, including crop_data.py and suitability.py.

Extract the files directly into the root of the GitHub repository and replace matching app files. Keep any LICENSE file you already created. In Streamlit Community Cloud, the main file path is app.py.

Core field features use free public sources. Gemini Cloud chat needs a server-side API key and internet; Ollama chat can run locally after its model is downloaded. Live lookups and map tiles require internet; offline field use needs saved/manual data and a preloaded disease model. Hosting and device costs may still apply. The local SQLite login/history is a prototype.
